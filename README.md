With this repository, you can reproduce the results of my MPhil thesis by following these steps:

One_Stage_MIP.py & One_Stage_MIP.cpp: Python(C++) and Gurobi code for solving binary programming model (2.9)

Relaxed LP.py & Relaxed LP.cpp:  Python(C++) code for the Linear Programming Relaxation of Problem (2.7)

Bender_decomposition_callback.py & Bender_decomposition_callback.cpp: Python(C++) code for the Benders’ decomposition method of Problem (2.5)
